발급: ClickUp 우상단 아바타 → Settings → All settings → ClickUp API → Generate. 표시된 pk_…는 Copy 버튼으로 복사하고, Bearer 접두어 없이 토큰만 붙여넣으세요.

ClickUp URL(/v/l/…)에는 리스트 ID가 안 나올 수 있어요. 리스트 찾아보기로 골라주세요. (직접 입력도 가능)

AI 사용을 위한 인증 값입니다. 사내 프록시를 쓰면 담당자에게 받은 접속 토큰을 입력하세요. (프록시 없이 OpenAI를 직접 쓰는 경우엔 실제 API 키 sk-…) 설정 안 하면 "AI로 다듬어 등록" 버튼은 숨겨집니다.

base URL은 담당자 로컬 PC에 띄운 사내 프록시 주소입니다. AI 요청이 이 프록시를 거쳐 OpenAI로 전달돼요. (담당자 PC의 프록시가 켜져 있어야 AI 기능 사용 가능)
