Chrome Extension · QA Bug Reporting

버그를 발견한 화면 그대로, 딸깍 한 번으로 ClickUp에 등록합니다.

화면·영상을 캡처하고 주석을 단 뒤, 콘솔 에러·재현 단계·환경 정보까지 자동으로 채워 ClickUp 태스크로 등록하는 QA 도구입니다. 리포트 작성 시간을 몇 분에서 30초 이내로 줄이는 것을 목표로 합니다.

화면 / 영역 / 전체 캡처 영상 녹화 주석 편집 웹 상태 자동 진단 자동 재현 스텝 AI 다듬기 ClickUp 원클릭

먼저 이렇게 보세요

모든 항목을 처음부터 읽을 필요는 없습니다. 지금 상황에 맞는 흐름부터 보세요.

처음 설치한 경우

  1. 빠른 시작으로 설치와 첫 캡처를 확인합니다.
  2. 설정에서 ClickUp 토큰·리스트를 등록합니다.
  3. ClickUp 등록으로 첫 리포트를 올려봅니다.

매일 쓰는 QA인 경우

  1. 작업별 길찾기에서 원하는 캡처를 고릅니다.
  2. 웹 상태 진단·재현 스텝을 함께 담습니다.
  3. AI로 다듬어 등록으로 리포트를 정리해 올립니다.

팀 배포 담당자인 경우

  1. 팀 배포에서 프록시를 켭니다.
  2. lib/team-config.js에 프록시 주소·토큰을 넣습니다.
  3. ZIP을 팀에 배포하고, 각자 ClickUp 토큰만 넣게 안내합니다.

1. 처음 3분 사용 순서

설치부터 첫 리포트 등록까지의 최소 흐름입니다.

1. 확장 설치

  1. 크롬 주소창에 chrome://extensions 입력
  2. 우측 상단 개발자 모드 켜기
  3. 압축해제된 확장 프로그램 로드 → 딸깍 폴더 선택
  4. 툴바에 아이콘이 생기면 완료

2. ClickUp 연결

  1. 툴바 아이콘 클릭 → 사이드 패널의 ⚙️ 설정
  2. ClickUp 개인 API 토큰 입력 → 연결 테스트
  3. 리스트 찾아보기로 등록할 리스트 선택 → 저장

3. 캡처

  1. 리포트할 페이지에서 툴바 아이콘 클릭
  2. 사이드 패널에서 화면 캡처 선택
  3. 필요하면 화살표·번호로 주석 추가

4. 등록

  1. 제목·내용 확인 (재현 단계·URL·시각 자동)
  2. ClickUp에 등록 또는 🤖 AI로 다듬어 등록
  3. 토스트가 뜨면 ClickUp에 태스크·첨부 생성 완료
첫 등록 전에 확인할 것

설정에서 ClickUp 토큰과 기본 리스트가 저장돼 있어야 등록됩니다. 토큰은 Bearer 접두어 없이 pk_… 형태 그대로 붙여넣습니다.

3. 화면 구성

딸깍은 별도 창이 아니라 크롬 사이드 패널에서 동작합니다. 페이지를 조작하는 동안에도 패널이 닫히지 않아 캡처·녹화·영역 선택에 유리합니다.

런처 뷰캡처 4종 버튼(화면·전체·영역·영상)이 있는 시작 화면입니다.
미리보기캡처된 이미지/영상을 보여주고, 이미지면 주석 도구가 열립니다.
웹 상태 진단콘솔 에러·실패 요청 건수를 카드로 요약해 보여줍니다.
리포트 폼제목·이슈 내용·재현 방법·URL·캡처 시각을 담습니다.
등록 버튼ClickUp에 등록 / 🤖 AI로 다듬어 등록 두 가지.
⚙️ 설정ClickUp 토큰·리스트, AI(프록시) 설정 페이지로 이동.

4. 캡처 4종

상황에 맞는 방식으로 화면을 담습니다. 캡처 후에는 미리보기 → (이미지면) 주석 → 리포트 폼으로 이어집니다.

버튼기능설명
화면 캡처보이는 영역현재 탭에서 눈에 보이는 영역을 즉시 캡처합니다. 가장 빠릅니다.
전체 페이지스크롤 스티칭페이지를 스크롤하며 여러 컷을 이어붙입니다. 고정 헤더가 중복되지 않게 처리합니다.
영역 선택드래그 크롭원하는 부분만 드래그해 잘라냅니다. 고해상도(배율)도 반영됩니다. ESC 또는 ✕ 취소 버튼으로 취소.
영상 녹화화면 녹화(webm)탭·창·전체 화면을 녹화합니다. 중지하면 미리보기에서 재생 후 첨부됩니다.
영상 녹화 팁

녹화 시작 시 공유 대상을 고르는 크롬 창이 뜹니다. 대상 탭/창을 선택하면 녹화가 시작되고, 완료 후 .webm으로 첨부됩니다.

5. 주석 편집

이미지 캡처 위에 바로 그릴 수 있는 캔버스 도구입니다. 무거운 외부 편집기 없이 패널 안에서 처리됩니다.

화살표

문제 지점을 가리킵니다.

형광펜

영역을 반투명하게 강조합니다.

단계 번호

클릭할 때마다 1, 2, 3… 자동 증가합니다.

텍스트

짧은 설명을 이미지에 직접 씁니다.

색상 변경과 실행 취소(Undo)를 지원합니다.

6. 웹 상태 자동 진단

QA가 개발자 도구를 직접 뒤지지 않아도, 페이지의 콘솔 에러와 실패한 네트워크 요청을 자동으로 수집합니다. iframe 내부까지 포함하며 중복은 제거됩니다.

무엇이 잡히나

JS 콘솔 에러, 4xx·5xx로 실패한 요청을 건수와 함께 요약합니다. 리포트 등록 시 내용이 설명에 자동 포함됩니다.

강력 새로고침 후 진단

버튼 한 번으로 캐시를 무시하고 새로고침한 뒤, 로드 중 발생하는 에러까지 잡아냅니다. (쿠키/캐시 이슈 재현에 유리)

7. 자동 재현 스텝

버그 재현까지 눌렀던 클릭·입력을 기억해 재현 방법을 자동으로 작성합니다. 손으로 재현 단계를 적을 필요가 줄어듭니다.

활용

기록된 행동이 리포트의 “재현 방법” 항목으로 정리되어, 개발자가 같은 순서로 재현하기 쉬워집니다.

8. AI로 다듬어 등록

메모·재현 스텝·콘솔 에러(설정 시 스크린샷까지)를 종합해 제목 / 프리컨디션 / 재현 단계 / 기대·실제 결과로 정리한 뒤 등록합니다. 등록한 리포트를 예시로 기억해 쓸수록 팀 스타일에 맞춰집니다.

어떻게 동작하나

OpenAI(gpt-4o-mini)가 내용을 정리합니다. 팀 환경에서는 담당자 PC의 로컬 프록시를 거쳐 호출되므로, 팀원은 실제 OpenAI 키 없이 사용합니다.

버튼이 안 보인다면

AI 접속 토큰이 설정되지 않으면 “🤖 AI로 다듬어 등록” 버튼은 숨겨집니다. (일반 ClickUp에 등록은 그대로 사용 가능)

데이터 처리

캡처·주석·웹 상태·설정은 브라우저(chrome.storage)에 로컬 저장됩니다. “AI로 다듬어 등록”을 누를 때만 리포트 내용과 (설정 시)스크린샷이 프록시를 거쳐 OpenAI로 전송됩니다.

9. ClickUp 등록

지정한 리스트에 태스크를 만들고 캡처 이미지/영상을 첨부합니다.

자동으로 채워지는 것

제목 형식 [고객사] 이슈 내용, 이슈 내용·재현 방법·URL·캡처 시각. 담당자는 본인으로 자동 배정됩니다.

멘션 표시

리포트 폼의 “멘션 표시” 입력칸에 이름/팀을 넣으면 본문 맨 아래 하이퍼링크로 들어갑니다.

10. 설정

사이드 패널의 ⚙️ 설정에서 한 번만 맞추면 됩니다.

ClickUp 연결 (각자 필수)

  1. 개인 API 토큰 발급 — ClickUp 우상단 아바타 → Settings → All settings → ClickUp API → Generate. 표시된 토큰은 Copy 버튼으로 복사 (Bearer 접두어 없이).
  2. 토큰 붙여넣기 → 연결 테스트 — “연결 성공 — 사용자: …”가 뜨면 정상.
  3. 리스트 찾아보기 — 워크스페이스 → 스페이스 → 폴더 → 리스트를 순서대로 골라 선택합니다. (ClickUp URL엔 리스트 ID가 안 보이는 경우가 많아 이 방식이 안전)
  4. 저장

AI (OpenAI · 로컬 프록시)

AI 관련 값(접속 토큰 · 모델 · base URL)은 배포본에 미리 설정되어 있어 비활성 상태로 표시됩니다. 팀원은 손댈 필요가 없습니다.

모델gpt-4o-mini고정

11. 팀 배포 (담당자용)

실제 OpenAI 키는 담당자 PC의 프록시에만 두고, 팀원에게는 프록시 주소와 접속 토큰만 배포합니다. 팀원은 실제 키를 볼 수 없습니다.

1) 프록시 실행 (담당자 PC)

  1. proxy/config.example.json을 config.local.json으로 복사
  2. openaiKey에 실제 OpenAI 키, accessToken에 팀에 나눠줄 토큰 입력
  3. proxy/start-proxy.bat 실행 → 콘솔에 실행 안내가 뜨면 정상
  4. 담당자 PC의 사내 IP 확인 (ipconfig → IPv4)
방화벽 · 사용량

팀원 접속을 위해 해당 포트(기본 8770) 인바운드를 허용해야 할 수 있습니다. OpenAI 대시보드에서 키에 월 사용량 한도를 걸어두면 만일의 유출에도 피해가 상한선 안에서 멈춥니다.

2) 기본값 심기 (배포본)

lib/team-config.js에 프록시 주소와 접속 토큰을 넣어두면, 팀원은 옵션을 만지지 않아도 AI가 바로 동작합니다.

export const TEAM_DEFAULTS = {
  openaiBaseUrl: 'http://10.20.132.30:8770/v1',
  openaiApiKey: 'ttalkkak-...(접속 토큰)',
  openaiModel: 'gpt-4o-mini',
};
실제 OpenAI 키는 여기에 넣지 마세요

team-config.js에는 프록시 주소·접속 토큰만 넣습니다. 실제 OpenAI 키(sk-…)는 담당자 PC의 proxy/config.local.json에만 있어야 합니다.

3) 팀원 설치

  1. ZIP을 받아 압축 해제
  2. chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램 로드 → 폴더 선택
  3. ⚙️ 설정에서 본인 ClickUp 토큰·리스트만 입력 (AI는 이미 설정됨)
AI를 쓰려면

담당자 PC의 프록시가 켜져 있고 사내망에 연결돼 있어야 합니다. 프록시가 꺼져 있으면 AI 버튼만 실패하고, 캡처·진단·ClickUp 등록은 그대로 동작합니다.
