# 딸깍 버그리포팅 (QA Capture to ClickUp)

> 화면을 캡처하고 주석을 단 뒤, 클릭 한 번(딸깍)으로 ClickUp에 버그 태스크를 등록하는 크롬 확장 프로그램.

QA가 버그를 발견한 순간부터 이슈 트래커에 리포트가 올라가기까지 걸리는 시간을 **몇 분 → 30초 이내**로 줄이는 것을 목표로 합니다. 재현 단계·콘솔 에러·환경 정보가 자동으로 채워지고, AI가 내용을 정리해 초안을 완성해줍니다. (캡처·주석·상태는 로컬 처리, AI 정리는 선택 기능)

## 📖 상세 가이드

### 📄 [프로젝트 설명자료 (PDF)](docs/딸깍%20버그%20리포팅.pdf)
프로젝트 소개·기능을 한눈에 — **저장소에서 클릭하면 바로 열립니다.**

참고
- 웹 버전 가이드: [docs/guide.html](docs/guide.html) (내려받아 브라우저로 열기)

## 주요 기능

### 캡처 4종
- 🖼️ **화면 캡처** — 지금 보이는 영역을 즉시 캡처
- 📄 **전체 페이지** — 스크롤하며 여러 컷을 이어붙임 (고정 헤더 중복 방지)
- ✂️ **영역 선택** — 드래그한 부분만 잘라 캡처 (고해상도 배율 반영)
- 🎥 **영상 녹화** — 탭 화면을 webm으로 녹화 (창·전체 화면도 가능, 대상 탭 자동 전환)

### 정리 & 자동화
- ✏️ **주석 편집** — 화살표 · 형광펜 · 단계 번호(자동 증가) · 텍스트, 실행 취소/색상
- 👆 **자동 재현 스텝** — 페이지에서의 클릭·입력을 기억해 재현 단계를 자동 작성
- 🔍 **웹 상태 자동 진단** — 콘솔 에러 · 실패한 네트워크 요청을 iframe까지 수집(중복 제거), 실시간 갱신 · 강력 새로고침 후 진단
- 🤖 **AI로 다듬어 등록** — OpenAI가 메모·재현 스텝·콘솔 에러(·이미지 인식 모델이면 스크린샷)를 종합해 **제목/프리컨디션/재현/기대·실제 결과**로 정리. 등록한 리포트를 예시로 기억해 **쓸수록 팀 스타일에 맞춰짐**

### 등록
- 📋 **ClickUp 원클릭 등록** — 지정한 리스트에 태스크 생성 + 이미지/영상 첨부
- 🙋 **자동 담당자 배정** & **멘션 표시**
- 🧩 **사이드 패널 UI** — 페이지를 조작하는 동안에도 패널이 유지됨

## 설치 (개발자 모드)

1. 이 저장소를 클론하거나 ZIP으로 내려받습니다.
2. 크롬에서 `chrome://extensions` 접속
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → 이 폴더 선택
5. 툴바에 아이콘이 생기면 완료 (코드 수정 후에는 카드의 🔄 새로고침)

## 설정

### ClickUp (필수)
1. 툴바 아이콘 → 사이드 패널의 ⚙️ (또는 "설정하기")
2. **개인 API 토큰** 입력 — ClickUp 우상단 아바타 → Settings → All settings → **ClickUp API** → Generate. 표시된 토큰은 **Copy 버튼**으로 복사 (Bearer 접두어 없이)
3. **연결 테스트** 로 확인
4. **리스트 찾아보기** 로 워크스페이스 → 스페이스 → 폴더 → 리스트를 골라 선택 후 **저장**

### AI (선택 · OpenAI)
1. **API 키 발급** — platform.openai.com → API keys
2. 옵션의 🤖 AI 섹션에 **API 키** 입력, **모델**은 `gpt-4o-mini`(권장·비우면 자동) 등, 이미지도 분석하려면 "스크린샷도 AI에 전송" 체크
3. **AI 연결 테스트** 로 확인 후 **저장**
   - 설정 안 하면 "AI로 다듬어 등록" 버튼은 숨겨집니다 (일반 등록은 그대로 사용)
   - (선택) Azure·사내 호환 엔드포인트는 옵션의 base URL에 입력

#### 팀 공용 키 — 사내 프록시 배포 (권장)
팀원에게 실제 OpenAI 키를 노출하지 않으려면 **호스트 PC 한 곳에서 프록시**를 돌리고,
팀원 확장에는 **서버 주소 + 접속 토큰**만 배포합니다. → [proxy/README.md](proxy/README.md)
- 호스트: `proxy/config.example.json` → `config.local.json` 복사·작성 후 `proxy/start-proxy.bat` 실행
- 팀원 옵션: base URL `http://<호스트 IP>:8787/v1`, API 키에는 **접속 토큰**(실제 키 아님) 입력
- 실제 키는 호스트 PC에만 있고 저장소·ZIP엔 포함되지 않습니다(`config.local.json` gitignore)

## 사용법

1. 리포트할 웹페이지에서 툴바 아이콘 클릭 → 사이드 패널 열림
2. 캡처(화면/전체/영역/영상) 선택
3. 이미지면 주석 추가 · 진단 카드에서 웹 상태 확인
4. 제목 등 확인 (재현 단계·URL·시각·콘솔 에러 자동)
5. **ClickUp에 등록** 또는 **🤖 AI로 다듬어 등록**

## 기술 스택 / 제약

- **Manifest V3**, 순수 **Vanilla JavaScript (ES Modules)**
- **번들러·프레임워크·TypeScript 사용 안 함** — 크롬이 소스 파일을 그대로 로드
- 상태 저장은 `chrome.storage` (localStorage 미사용)
- 외부 라이브러리 없이 **Canvas API**로 주석, **getDisplayMedia**로 녹화 직접 구현
- **로컬 우선** — 캡처·주석·웹 상태·설정은 `chrome.storage`에 로컬 저장. 외부 전송은 ClickUp 등록과 (선택 시) OpenAI AI 정리 때만

## 폴더 구조

```
manifest.json          MV3 매니페스트
background/            서비스 워커 (패널 동작 설정)
sidepanel/             메인 UI (캡처 · 주석 · 리포트 · AI)
content/               페이지 주입 (영역 선택 · 녹화 컨트롤 · 로그 수집)
options/               ClickUp · AI 설정
lib/                   storage · clickup · openai
icons/                 확장 아이콘
docs/                  사용 가이드 · 설명자료(PDF)
proxy/                 (선택) 사내 OpenAI 프록시 — 팀 공용 키를 서버에만 보관
```
