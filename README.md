# 딸깍 버그리포팅 (QA Capture to ClickUp)

> 화면을 캡처하고 주석을 단 뒤, 클릭 한 번으로 ClickUp에 버그 태스크를 등록하는 크롬 확장 프로그램.

QA가 버그를 발견한 순간부터 이슈 트래커에 리포트가 올라가기까지 걸리는 시간을 **몇 분 → 30초 이내**로 줄이는 것을 목표로 합니다.


## 📖 상세 가이드

기능·설정·설치/배포 안내는 **[docs/guide.html](docs/guide.html)** 참고 (브라우저로 열기).
AI 서버가 꼬였을 때는 **[scripts/start-ai-server.bat](scripts/start-ai-server.bat)** 을 실행하면 Ollama가 확장 접속 허용 상태로 재시작됩니다.

## 주요 기능

- 🖼️ **화면 캡처** — 보이는 영역을 즉시 캡처
- ✏️ **주석 편집** — 화살표 · 형광펜 · 단계 번호 · 텍스트를 캡처 위에 바로
- 📋 **ClickUp 원클릭 등록** — 미리 지정한 리스트에 태스크 생성 + 이미지 첨부
- 📝 **리포트 템플릿** — 제목/재현 방법/URL/캡처 시각 자동 정형화 (마크다운)
- 🙋 **나에게 배정** — 등록과 동시에 담당자 지정
- 🧩 **사이드 패널 UI** — 페이지를 조작하는 동안에도 패널이 유지됨
- 🤖 **로컬 AI 리포트 정리** — Ollama가 메모·재현 스텝·콘솔 에러·스크린샷을 종합해 정형화 (외부 API 미사용)

### 예정 (로드맵)

- 전체 페이지 캡처(스크롤 스티칭), 영역 선택
- 동영상 녹화 (tabCapture + MediaRecorder)
- 콘솔 에러 · 실패한 네트워크 요청 자동 수집

## 설치 (개발자 모드)

1. 이 저장소를 클론하거나 ZIP으로 내려받습니다.
2. 크롬에서 `chrome://extensions` 접속
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → 이 폴더 선택
5. 툴바에 아이콘이 생기면 완료

## 설정

1. 툴바 아이콘 클릭 → 사이드 패널의 ⚙️ 또는 "설정하기"
2. **ClickUp 개인 API 토큰** 입력
   - ClickUp 우상단 아바타 → Settings → All settings → **ClickUp API** → Generate
   - 표시되는 토큰은 마스킹되어 있으니 **Copy 버튼**으로 복사 (Bearer 접두어 없이 토큰만)
3. **연결 테스트** 로 토큰 확인
4. **리스트 찾아보기** 로 워크스페이스 → 스페이스 → 폴더 → 리스트를 골라 선택 후 **저장**

## 사용법

1. 리포트할 웹페이지에서 툴바 아이콘 클릭 → 사이드 패널 열림
2. **화면 캡처** 클릭
3. 캡처 이미지에 주석(화살표/형광펜/번호/텍스트) 추가
4. 제목·설명 작성 (URL·캡처 시각은 자동)
5. **ClickUp에 등록** → 태스크 링크로 이동해 확인

## 기술 스택 / 제약

- **Manifest V3**, 순수 **Vanilla JavaScript (ES Modules)**
- **번들러·프레임워크·TypeScript 사용 안 함** — 크롬이 소스 파일을 그대로 로드
- 상태 저장은 `chrome.storage` (localStorage 미사용)
- 외부 라이브러리 없이 Canvas API로 주석 직접 구현
- 완전 로컬 처리 — 별도 백엔드 서버 없음

## 폴더 구조

```
manifest.json          MV3 매니페스트
background/            서비스 워커 (패널 동작 설정)
sidepanel/             메인 UI (캡처 · 주석 · 리포트 폼)
options/               ClickUp 토큰 · 리스트 설정
lib/                   storage · clickup API 래퍼
icons/                 확장 아이콘
```
